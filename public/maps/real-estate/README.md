# 부동산 지도 경계

본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서
공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor,
https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다.

- 원본: https://github.com/vuski/admdongkor/blob/d5d5a821c8de6cc337d47eeca604d7af76271c9b/ver20261001/HangJeongDong_ver20261001.geojson
- 경계 기준: 2026-10-01. 과거 행정구역으로 복원한 지도가 아닙니다.
- 이 프로젝트의 가공: 행정동을 시군구 코드(sgg)로 합침, 일반구를 시 아래 묶음,
  시도 경계 합침, 경도×0.79 평면 투영, 0.001도 단순화, 화면 좌표로 변환.
- regions.json: 탐색 트리와 각 노드에 포함되는 원본 법정동 시군구 코드.
- 지역별 JSON: 기본 640×540 viewBox의 SVG 경로. viewBox 필드가 있으면 해당 범위를 사용하며 내부 구멍은 evenodd로 렌더링.
- 전국 지도에서는 서쪽 외곽 도서 4개 경로와 울릉·독도 5개 경로를 확대·이동했다. 모양은 보존하되 서해 도서는 2배, 울릉도 주변은 2.5배, 독도는 16배로 확대했다. 제주 본섬과 인접 도서는 함께 본토 가까이 이동하고, 추자도는 원래 위치를 유지한다. 전국 뷰포트 여백을 줄여 지도 표시 크기를 키웠다. 섬 이름을 표시하고 상세 설명은 화면의 ⓘ에 제공한다. 시도 이하 지도에도 외곽 도서 묶음의 이동·확대를 적용한다. 가까운 섬은 같은 묶음으로 유지하고 본체에서 떨어진 묶음만 빈 해역에 배치한다. 지역 ID와 통계 소속은 그대로이며, 이동한 묶음과 기존 지역의 겹침을 검사한다. 변경된 상세 지도는 `islands_adjusted`와 여백을 줄인 `viewBox`를 갖는다.
- 면적·거리 측정이나 법적 경계 확인용으로 사용할 수 없습니다.
